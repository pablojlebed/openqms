# Appendix 2 — Item Storage and Disposal Register

**Parent procedure:** [13 – Handling of Items Received for Testing](./)

## Purpose

To provide a single, current point of reference for the storage location and disposition status of every item in the laboratory's custody — from receipt through return or disposal. This register lets the laboratory locate any item promptly and identify items approaching or past the end of their retention period.

## Instructions

1. **Reception personnel** add a new entry when an item is logged in ([Appendix 13-App-01](./appendix-01-item-receipt-condition-record)).
2. Storage location is updated whenever an item is moved.
3. The **Technical Manager** or **Quality Manager** records the retention period, disposition decision, and disposal or return details as they occur.
4. The **Quality Manager** reviews the register periodically (at least quarterly) to identify items approaching the end of their retention period.
5. This register is a controlled document managed per [Procedure 00 — Document and Record Control](../00-document-record-control/index.md).
